# Imon 0.1.0 发布功能清单

## F01 主机管理与采集

- 在 macOS、Linux 和 Windows 上使用桌面版，启动后直接进入主机管理；桌面版不启动 Web 服务或监听 HTTP 端口
- 单独启动 Web 版后，用普通本机地址在浏览器中访问；地址可反复打开或刷新，无需一次性启动链接
- Web 版和桌面版提供相同的业务界面和操作
- 切换栏目和详情时异步加载，不重载整个面板
- 业务表格按可用窗口高度分配固定区域，表头固定，长列表在表格内滚动；分页按钮留在列表外
- 通过 SSH 绑定使用 systemd 的 Linux 主机，通过 Kubernetes API 绑定集群，两类目标可独立绑定，绑定数量不设产品上限
- 为 SSH 登录选择本机私钥文件，也可手动填写绝对路径；应用只引用文件，不上传私钥
- 从本机 `known_hosts` 核验 SSH 服务器身份；首次遇到未记录的主机时显示指纹供核对，拦截已信任主机的密钥变更
- 保存主机时自动测试 SSH 连接，通过后保存绑定并立即采集主机概况，失败时保留输入；集群连接先测试再保存
- 编辑已保存的连接配置，查看 SSH 或 API 连接状态
- 主机列首行显示名称，次行弱化显示连接地址（IP 或主机名）
- 查看主机系统版本；CPU、内存、磁盘均以首行显示占用百分比、次行显示已用量与总量，集群显示就绪节点和异常 Pod 数量
- 点击主机列表的整行打开主机详情；从集群列表打开集群资源详情
- 从主机列表的「操作」下拉菜单安装或卸载防火墙只读采集授权、创建告警及解绑，保留独立的编辑按钮；主机详情和网络防火墙页签只展示授权状态，不提供独立授权管理页
- 宿主机与 Kubernetes 节点手动关联
- 解绑主机或集群时停止对应采集、暂停关联规则并保留历史告警，解绑集群时清除其节点关联
- 解绑主机前确认防火墙读取授权和暂存脚本已清理；主机离线、权限不足或结果未确认时保留绑定，集群解绑不受此检查影响
- 从主机或集群列表带入对应目标创建告警
- 打开业务页或切换目标、页签时，异步读取当前范围的快照，没有采集记录时执行首次采集；快速切页会取消尚未提交的请求，返回同一范围时复用已提交的任务
- 在一级栏目「采集设置」开启或关闭定时采集，并配置主机性能与服务、主机网络、Kubernetes 资源的采集周期；关闭定时采集仍可执行首次采集
- 定时采集开启时，当前页面按周期刷新所需数据；离开页面后，后台只采集已启用且有效的告警规则所需数据。不同目标可并发处理，同一目标不并发发起多组采集
- 在主机管理、服务、主机详情、网络及集群详情的右上角查看当前范围的采集进度和分秒倒计时；点击倒计时可立即采集当前页面的数据

## F02 服务

- 在服务栏目统一展示和搜索宿主机 systemd 服务与 Kubernetes Deployment
- 查看目标的服务采集错误，区分超时、权限不足、未采集与采集成功但无数据；服务采集失败时保留最近一次成功的数据
- 按部署来源、主机、集群、命名空间和服务状态筛选；服务表格不单列部署来源
- 按服务名称、目标、状态、CPU 占用和内存占用升序或降序排序
- 查看实际采集到的 CPU 和内存占用，缺失的指标留空；Kubernetes Metrics API 不可用时仍可查看已采集到的 Deployment 和运行状态
- 查看服务的部署位置、运行状态和最近采集时间，查看 Deployment 的就绪副本及期望副本
- 展示运行中、失败、停止状态，采集确认启动过程时展示启动中；数据过期时保留最近一次采集结果和时间
- 启动和停止明确授权的 systemd 服务单元及明确授权且独立手动管理的 Kubernetes Deployment
- 启动已停止或失败的 systemd 服务，停止运行中的服务；启动中暂停重复操作
- 启动已缩容到零的 Deployment，恢复停止前的副本数；没有记录时指定启动副本数
- 查询启停任务结果及服务状态，单独查看 Deployment 副本数写入与达标结果；启停不改变 systemd 的开机策略
- 从服务列表带入当前服务创建告警

## F03 主机详情

- CPU 使用率监控
- 内存使用率监控
- 按挂载点监控磁盘容量与使用率，在同一列分两行显示百分比和已用量／总量
- 按网卡监控收发速率，在同一列显示接收和发送；宽屏时磁盘与网卡列表并排显示
- 按主机和时间范围查询性能历史趋势与最近采集时间
- 从磁盘挂载点创建告警，预填挂载点和磁盘使用率

## F04 主机网络

- 查询网络接口的地址、链路状态和 MTU
- 查询路由表的目的网段、下一跳、出口接口和优先级
- 查询监听端口的协议、绑定地址、端口及可读取的进程信息
- 只读查询 UFW、nftables 和 iptables-legacy 防火墙规则，展示适用的表、链、匹配条件和动作
- 单独查看接口、路由、监听端口和防火墙的最近成功采集时间及数据是否过期
- 区分防火墙无规则、未启用、不可读、未检测到工具和不支持
- 自动识别防火墙只读采集授权，在主机详情和防火墙页签查看授权状态、已安装版本以及可用的新版本；版本以关联应用版本加短码显示，例如 `v0.1.0 8645c`
- 从主机列表「操作」菜单安装或卸载防火墙只读采集授权；自动操作缺少权限时可使用独立管理员 SSH 凭据，或确认上传脚本并在目标主机手动执行后重新核验
- 连接配置不变时沿用已识别的安装状态，重启或更新应用后保留关联；修改连接配置后重新检测
- 确认解绑主机时自动清理授权助手及已知暂存脚本；权限不足时可使用独立管理员 SSH 凭据，或确认上传清理脚本，由管理员进入 `/bin/sh` 执行清理命令，再回到应用重新核验并完成解绑
- 从告警规则编辑器为指定主机的协议、绑定地址和端口创建监听告警

## F05 Kubernetes 资源

- 查看集群 API 连接状态和最近成功采集时间
- 查询命名空间的状态及 Deployment、Pod 和 Service 数量
- 查询 Deployment 的就绪副本和期望副本
- 查询 Pod 的阶段、就绪状态和所在节点
- 查询 Service 的类型、端口及适用时的就绪后端数
- 查询节点的 Ready 状态和关联宿主机
- 按命名空间筛选 Deployment、Pod 和 Service
- 从 Deployment、Pod 和节点带入当前对象创建告警

## F06 告警规则与事件

- 告警规则创建、编辑、启用和停用
- 告警规则绑定主机性能指标、systemd 服务、监听端口、Kubernetes 节点、Deployment、Pod 或采集失联
- 配置阈值或状态条件，以及持续时长或连续采样次数
- 告警级别配置
- 持续异常去重与恢复记录
- 排除过期或不可读的样本，避免误触发或误恢复业务告警
- 告警默认打开事件列表，按触发时间倒序展示全部事件，支持按活动、已恢复或未读筛选
- 查看事件的级别、规则、对象、触发条件、最新值、触发与恢复时间、数据来源及各渠道投递结果
- 从事件详情跳转到数据来源，返回列表时保留筛选条件
- 在同一事件列表和详情查看采集异常；按已启用的通知配置投递
- 打开未读事件时标记已读并更新告警菜单未读计数

## F07 通知

- 为面板通知、Telegram 和邮箱分别设置全局启用开关
- 每条告警规则可分别开启或关闭面板通知、Telegram 和邮箱
- 渠道全局启用且规则选中时，投递告警触发与恢复通知
- 面板通知直接在告警事件列表标记未读，并在告警菜单显示未读计数
- 配置 Telegram 机器人凭据引用与接收会话
- 配置邮箱服务器、凭据引用与收件人
- 发送测试通知并查询发送结果
- 所有通知渠道关闭时仍记录告警事件

## F08 版本和本地数据

- 在侧栏底部查看当前版本 `v0.1.0`；点击版本号查看本地构建的更新仓库配置状态
- 备份本地 SQLite 状态库，并在停止客户端后从备份恢复
