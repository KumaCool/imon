# Imon 0.1.0 界面草图

以下为独立 Web 版与 macOS、Linux、Windows 桌面版共用的等宽字符画。方括号表示界面控件，`*` 标记当前标签，`v` 表示下拉选项。对象和数值均为示例。

## 1. 服务列表

```text
+-------------+--------------------------------------------------------------------------------------+
|   主机管理  | Imon / 服务                                                                o 采集2/4 |
|  > 服务     | [*全部*] [宿主机] [Kubernetes]  [主机 / 集群 v] [状态 v] [搜索服务]                  |
|   网络      | 选择 Kubernetes 时可按命名空间筛选                                                   |
|   告警 (1)  |                                                                                      |
|   采集设置  | 服务       部署来源    类型        位置                    状态    操作              |
|             | <服务 A>   宿主机      systemd     <主机 A>                运行中  [停止] [创建告警] |
|             | <服务 B>   宿主机      systemd     <主机 B>                失败    [启动] [创建告警] |
|             | <服务 C>   Kubernetes  Deployment  <集群 A> / <命名空间>   运行中  [停止] [创建告警] |
|  [v0.1.0]   | <服务 D>   Kubernetes  Deployment  <集群 A> / <命名空间>   停止    [启动] [创建告警] |
+-------------+--------------------------------------------------------------------------------------+
```

桌面应用启动后直接进入「主机管理」，不启动 Web 服务或监听 HTTP 端口。独立启动 Web 版后，浏览器打开普通本机地址进入同一界面，地址可反复打开和刷新。左侧一级菜单依次为「主机管理」「服务」「网络」「告警」「采集设置」。机器性能、集群详情和指定主机的网络详情都是二级页面。一级「网络」显示首台已绑定主机的网络详情，可切换主机；未绑定主机时显示空态。机器性能也可直接打开同一主机的网络详情。

切换菜单、标签或详情时，导航保持不动，主内容异步加载。已有快照先显示，并标明观察时间。只处理当前视图所需的数据组，例如查看「路由」不读取监听端口或防火墙。没有采集记录时执行首次采集，已有记录时只在开启定时采集且周期到期后刷新当前页面。快速切换会取消尚未提交的页面采集，返回同一范围时复用已经提交的任务。

页首标题与操作按钮对齐，同一行表单输入、选择框和按钮等高。各业务表格按窗口可用高度分配列表区域，表头在列表内固定、分页放在列表外；长列表只在自身区域内滚动，窄窗时可在列表内横向滚动。

采集状态固定在各业务页页头右上角，范围随当前页签、目标及数据组变化。相关任务正在处理时显示进度，完成后显示当前页面或关联告警最早一次计划的倒计时。没有计划时留空，不显示其他页面的任务或倒计时。两种状态不同时显示。

「服务」混合展示宿主机的 systemd 服务与 Kubernetes Deployment。可按部署来源、主机或集群、状态和名称筛选，Kubernetes 条目可再按命名空间筛选。Kubernetes Service 对象和 Pod 原始状态在集群详情中查看。未识别归属的监听进程在网络详情中查看。

服务状态统一为「运行中」「失败」「停止」。采集明确识别到启动过程时显示「启动中」。运行中显示 [停止]，停止或失败显示 [启动]，启动中暂停重复操作。宿主机服务和集群工作负载使用相同的按钮规则。只有具备目标操作权限时才可启停。[创建告警] 带入当前服务。数据过期时保留最近一次成功结果并标明观察时间；采集异常在「告警 → 事件」查看。

|                                  2 / 8 核         8 / 16 GiB         40 / 100 GiB                               |
| <主机 B>    --          失败      --               --                  --                     [编辑] [操作 v]   |
|                                                                                              +---------------+  |
|                                                                                              | 安装授权      |  |
|                                                                                              | 创建告警      |  |
|                                                                                              | 解绑          |  |
|                                                                                              +---------------+  |
+-----------------------------------------------------------------------------------------------------------------+

主机列表显示系统版本，CPU、内存和磁盘首行显示占用百分比，次行显示已用量与总量。磁盘摘要对应使用率最高的有效挂载点；缺测显示 `--`。

绑定与解绑操作示意：

```text
+--------------------------------------------------------------------------------------------------+
| 绑定主机                                                                                         |
| 显示名称     [<主机名称>]                SSH 地址   [<主机地址>]                                 |
| 登录用户     [<登录用户>]                SSH 端口   [22]                                         |
| SSH 私钥路径 [<绝对路径>] [选择文件]     关联节点   [<集群> v] [<节点> v]                        |
|                                                                                                  |
| 首次连接：SSH 目标 <主机地址>:22，指纹 SHA256:<指纹>               [确认指纹并测试]              |
|                                                                                                  |
| 状态：保存时自动测试                                                          [保存绑定] [取消]  |
+--------------------------------------------------------------------------------------------------+
| 绑定 Kubernetes 集群                                                                             |
| 显示名称     [<集群名称>]                kubeconfig [<引用>]                                     |
| Context      [<上下文> v]                                                                        |
| 状态：等待测试                                                      [测试连接] [保存绑定] [取消] |
+--------------------------------------------------------------------------------------------------+
| 确认解绑 <对象名称>？                                                                            |
| 停止采集并暂停关联规则，历史告警保留。                                        [取消] [确认解绑]   |
+--------------------------------------------------------------------------------------------------+
```

主机通过 SSH 采集，集群通过 Kubernetes API 采集，两者可独立绑定。SSH 私钥通过本机文件对话框选择，也可填写绝对路径；取消选择保留原值。不要求手填服务器公钥。若本机已有可信记录，直接核验；首次遇到未记录的主机时，框内显示目标及指纹，核对后继续测试。如果已信任的服务器密钥变化，测试失败并保留输入，普通确认按钮不覆盖旧信任。配置跳板时，分别确认跳板和目标。列表显示 SSH 或 API 状态；集群列表保留最近成功时间。主机保存时自动测试连接，失败时保留输入。主机绑定与防火墙辅助脚本授权可独立完成。

点击主机行打开该主机的机器性能；点击操作按钮或选中文本不打开详情。主机的 [操作 v] 包含 [安装授权] 或 [卸载授权]、[创建告警] 及 [解绑]，[编辑] 保持独立。集群行的 [查看] 打开该集群的资源详情。[创建告警] 带入当前主机或集群。

安装与卸载均从中心端发起。自动处理因远端管理员权限不足而停止时，先询问是否上传对应脚本；经确认后上传，并展示可复制的 CLI 命令供管理员执行。卸载后，仍需提升权限才能读取的防火墙采集显示「不可读」，其他主机数据继续采集。

解绑只停止本系统对该对象的采集，不删除远端服务、节点或规则。解绑集群时清除其节点关联，独立绑定的宿主机继续采集。

```text
+--------------------------------------------------------------------------------------------------+
| 网络（只读）   [<主机 A> v]                                                        o 采集1/2 [机器性能] |

+--------------------------------------------------------------------------------------------------+
| 其他标签的内容示例                                                                               |

|              <接口 A>         UP             192.0.2.10/24               1500                    |
|                                                                                                  |

|              main           0.0.0.0/0             192.0.2.1          <接口 A>       100          |

+--------------------------------------------------------------------------------------------------+
```

每个标签独立显示最近成功采集时间以及数据是否过期。监听端口表没有「操作」列；端口告警从「告警 → 新建规则 → 监听端口」选择主机、协议、绑定地址和端口。

**防火墙只读授权**

1. 由主机管理员在采集账号不可写的系统目录安装一个 root 所有的无参读取脚本。支持 UFW、nftables 和 iptables-legacy，辅助脚本按后端执行对应的只读查询。
2. 管理员用 `visudo` 配置 sudoers：只向专用 SSH 采集账号授予该脚本的 `NOPASSWD: NOSETENV:` 权限，并用 `""` 限定无参调用。采集端通过 `sudo -n` 执行，不等待密码；不开放通用 sudo、root SSH、任意 `nft` 命令或提权 shell。
3. 用采集账号验证：无参调用返回可解析 JSON，带参数调用不被授权；撤销对应 sudoers 条目后，无参调用也应被拒绝。没有授权时显示「不可读」，后端未适配时显示「不支持」，只有成功读取且确实没有规则时才显示空列表。

+--------------------------------------------------------------------------------------------------+

### 6.4 通知渠道

```text
+--------------------------------------------------------------------------------------------------+
| 告警   [事件] [规则] [*通知渠道*]                                                                |

| 渠道          启用    配置                                                                       |

+--------------------------------------------------------------------------------------------------+
```

「通知渠道」为面板通知、Telegram 和邮箱提供全局启用开关。渠道全局启用且被规则选中时才投递。面板通知将对应事件标记为未读，并更新「告警」菜单的未读计数。异常持续期间不重复发送，确认恢复后按选中的渠道通知。过期或不可读的数据不触发、也不恢复业务告警。采集失联可单独建规则。

## 7. 采集设置

```text
+-------------+----------------------------------------------------------+
|   主机管理  | 采集设置                                                 |
|   服务      | [x] 定时采集（当前页面及有效告警规则）                    |
|   网络      | 主机性能与服务  [60] 秒    主机网络  [120] 秒            |
|   告警      | Kubernetes 资源 [90] 秒                                  |
|  > 采集设置 |                                                          |
|             |                                                          |
|  [v0.1.0]   | [保存]                                                   |
+-------------+----------------------------------------------------------+
```

开启定时采集时，按照设置分别刷新当前停留的业务页与已启用且有效的告警规则所需的数据组；离开页面后，只有告警规则继续定时采集。不同目标可并发处理；同一目标不同时发起多组采集，也不因为一次请求而采齐所有分组。关闭定时采集仍可在进入页面时进行首次采集。不设全量采集、逐目标采集或重试按钮。

采集设置只保留设置表单，进度及倒计时不在此栏目显示。采集异常在「告警 → 事件」查看，按现有通知配置投递；不另设采集详情、进度弹窗或失败列表。

## 8. 侧栏版本气泡

```text
+-------------+-----------------+
|  > 主机管理 | 主机管理        |
|   服务      |                 |
|   网络      |                 |
|   告警      |                 |
|   采集设置  |                 |
|             | 当前版本 v0.1.0 |
|  [v0.1.0]   | 未配置更新仓库  |

```

本地构建点击版本号展开气泡，不切换页面。未配置更新仓库时，不检查更新、不显示更新红点。
